## ✨ About this repository

I use this repository as a hands-on space to strengthen my TypeScript fundamentals and practise writing code that is safer, clearer, and easier to maintain. It brings together **eight TypeScript problem solutions** in `solutions.ts` and short technical write-ups that explain concepts in my own words.

The goal is simple: understand the idea, apply it in code, and keep a useful reference I can return to as I build more with TypeScript.

## 🧭 What you'll find here

| File                                             | What's inside                                                                                   |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| [`solutions.ts`](./solutions.ts)                 | Eight practical TypeScript solutions, including object-oriented programming concepts.           |
| [`type-vs-interface.md`](./type-vs-interface.md) | A comparison of `type` aliases and `interface`, with guidance on when to use each.              |
| [`type-narrowing.md`](./type-narrowing.md)       | A practical introduction to type narrowing using `typeof`, `instanceof`, and the `in` operator. |

## 🧩 Concepts explored

- **TypeScript fundamentals:** basic types, optional parameters, default parameters, and rest parameters.
- **Data modelling:** readonly tuples, interfaces, and type aliases.
- **Safer runtime checks:** type narrowing with built-in JavaScript operators.
- **Reusable code:** generics and their role in writing flexible, type-safe functions.
- **Asynchronous programming:** working with Promises.
- **Object-oriented programming:** applying OOP ideas with TypeScript.

## 🚀 Getting started

1. Clone or download the repository.
2. Open the project folder in your editor.
3. Start with `solutions.ts` to explore the code examples, then read the two topic notes for additional context.

To run or experiment with the code locally, use a TypeScript-compatible environment such as [the TypeScript compiler (`tsc`)](https://www.typescriptlang.org/docs/) or a TypeScript runtime configured in your project.
